## 全书逻辑主线

- **第一篇（第1-2章）：** 为什么变了 → 怎么定方向
- **第二篇（第3-4章）：** 抓什么需求（关键词）→ 用什么承接（内容中台）
- **第三篇（第5-7章）：** 怎么组织流量（账户）→ 怎么AI放大（智能投放）→ 数据怎么准（转化追踪）
- **第四篇（第8-11章）：** 怎么承接点击（创意+落地页）→ 怎么变成交（销售闭环）→ 怎么用数据优化（数据分析）→ 怎么沉淀长期流量（SEO融合）
- **第五篇（第12-13章）：** 怎么避坑、怎么用工具与新入口（风险+生态+GEO）→ 谁来做、怎么成（团队+案例）

> **一句话总结：** 前 4 章解决「流量从哪来」，第 5–7 章解决「怎么组织流量并交给 AI」，第 8–11 章解决「流量怎么变成钱」，后 2 章解决「怎么持续放大和落地」，每一环都有具体方法论，不再有「半截漏斗」。
